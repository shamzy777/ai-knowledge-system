# Generative AI（生成式 AI）

## One-sentence Definition / 一句話定義

Generative AI（生成式 AI）models a space or distribution of possible outputs so the same task context can yield more than one plausible result.

Source: S03, pp. 4–12, 93–98.

## Why It Matters / 為什麼重要

It explains why variety can be an intended behavior rather than merely an error, while still leaving reliability to be evaluated separately.

Source: S03, pp. 4–10, 97–98.

## Prerequisites / 先備概念

- [[distribution]]
- [[sampling]]

Source basis: S03, pp. 4–12, 93–98.

## Core Idea / 核心概念

S03 contrasts a fixed deterministic mapping with systems that represent variation through a random latent input or probability-based output choice. Its final comparison treats generative and discriminative labels as task framings with shared probabilistic foundations, not completely different principles.

Source: S03, pp. 4–12, 93–98.
