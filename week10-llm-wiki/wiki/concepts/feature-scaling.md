# Feature Scaling（特徵縮放）

## One-sentence Definition / 一句話定義

Feature Scaling（特徵縮放）resets numeric feature ranges or distributions before model training, such as standardization or division by an image maximum. Source: S01 pp. 2, 4; S06 pp. 8–12, 36–38, 62–66.

## Why It Matters / 為什麼重要

It is a recurring bridge from raw numeric data to stable practical network input. Source: S06 pp. 8–12, 36–38, 62–66.
