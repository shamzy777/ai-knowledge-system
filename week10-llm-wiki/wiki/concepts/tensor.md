# Tensor（張量）

## One-sentence Definition / 一句話定義

A Tensor（張量）is a multidimensional numeric array used to represent model inputs, intermediate layer values, and outputs. Source: S01 p. 2; S02 pp. 3–13, 41–50.

## Why It Matters / 為什麼重要

Neural-network functions operate on numeric structures, so tensor shape connects data representation to layer computation. Source: S02 pp. 3–13, 41–50.

## Prerequisites / 先備概念

- Scalars, vectors, matrices, and array shape.

## Core Idea / 核心概念

S02 repeatedly frames inputs and layer outputs as tensors/representations; S01 gives a handwritten dimensional hierarchy. Source: S01 p. 2; S02 pp. 3–13, 41–50.
