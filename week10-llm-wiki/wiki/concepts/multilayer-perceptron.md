# Multilayer Perceptron（多層感知器）

## One-sentence Definition / 一句話定義

A Multilayer Perceptron（多層感知器, MLP）stacks fully connected layers with nonlinear activations between input and output. Source: S02 pp. 41–50; S05 pp. 7–15.

## Why It Matters / 為什麼重要

Hidden layers let the network represent nonlinear mappings, and the same structure is used in the course regression and classification implementations. Source: S05 pp. 6–15; S06 pp. 3–17, 29–44, 59–71.

## Core Idea / 核心概念

Each layer transforms the previous representation; architecture, initialization, activation, loss, metric, and optimizer jointly define the trainable system. Source: S01 p. 7; S02 pp. 41–50; S05 pp. 10–31.
