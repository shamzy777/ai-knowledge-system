# Prompt Engineering（提示工程）

## One-sentence Definition / 一句話定義

Prompt Engineering（提示工程） supplies an LLM with relevant information and clear instructions about the task, output, and audience.

Source: S04, pp. 21, 100–115.

## Why It Matters / 為什麼重要

The model cannot use unstated context, and ambiguous instructions make desired output harder to obtain.

Source: S04, pp. 21, 100–115.

## Source Perspectives / 來源觀點

S09 treats a prompt as inference-time context and distinguishes prompting from parameter-updating training stages.

Source: S09, book pp. 21–24.

## Prerequisites / 先備概念

- [[large-language-model]]
- Task and audience definition（任務與讀者定義）

Source basis: S04, pp. 21, 100–115.

## Core Idea / 核心概念

S04 proposes a human-in-the-loop sequence: provide domain knowledge, ask the model to interview for missing context, request a draft/specification, verify information, and personally review and revise the result.

Source: S04, pp. 21, 100–115.

## Concept Relationships / 概念關係

- application: [[inference]] — supplies context and instructions without changing model parameters (S09 book pp. 21–24).
