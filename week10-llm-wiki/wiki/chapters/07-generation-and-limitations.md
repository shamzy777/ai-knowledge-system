# 7. Generation and Limitations（生成與限制）

This chapter is a navigation/learning structure, not a canonical concept.

## Learning goal / 學習目標

Understand how inference selects outputs, how users guide the model, and why fluent output still requires evaluation.

## Approved conflict treatment

The canonical Hallucination definition follows S09's narrower technical framing: fluent output that is ungrounded or incorrect. S04's broader creative/generative framing remains an explicitly attributed Course Perspective on the concept page.

## Teaching-path boundary

The later teaching-path phase starts from `Tokenization → Embedding → Self-Attention → Transformer → Language Model → Large Language Model → Softmax / Sampling`. This chapter does not create teaching HTML or finalize that bounded path.
