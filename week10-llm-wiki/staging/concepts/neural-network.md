# Neural Network（神經網路）

## One-sentence Definition / 一句話定義

A Neural Network（神經網路） is a parameterized function built from layers of computational units that transform numeric inputs into outputs.

Source: S04, pp. 5, 12–14.

## Source Perspectives / 來源觀點

S02 presents a neural network as a learned numeric function composed from neurons/layers; S05 adds perceptron-to-MLP structure and explicit training components; S06 demonstrates the same model family in regression, binary classification, and ten-class classification. S01/S07 are handwritten overview corroboration only.

Source: S02, pp. 28–50, 59–75; S05, pp. 3–20; S06, pp. 3–89; S01, pp. 1, 7; S07, full image.

## Why It Matters / 為什麼重要

S04 uses neural networks as the computational foundation for sequence models and language generation.

Source: S04, pp. 5, 12–14.

## Prerequisites / 先備概念

- Numeric input representations（數值輸入表示）
- Function-learning framing（函數學習觀點）

Source basis: S04, pp. 5, 12–14.

## Core Idea / 核心概念

S04 presents hidden layers and neurons as repeated tensor transformations. The source uses this as prerequisite framing and does not provide a complete training treatment.

Source: S04, pp. 5, 12–14.
