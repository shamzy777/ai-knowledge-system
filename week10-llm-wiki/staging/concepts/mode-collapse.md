# Mode Collapse（模式崩塌）

## One-sentence Definition / 一句話定義

Mode Collapse（模式崩塌） is a GAN failure mode in which many latent inputs produce only a narrow range of outputs.

Source: S03, p. 35.

## Why It Matters / 為什麼重要

A generator can appear realistic while still failing to cover the variety of the data distribution.

Source: S03, p. 35.

## Core Idea / 核心概念

S03 visualizes the failure as outputs collapsing onto only some modes. Its claim that WGAN resolves the problem is retained as a simplified course statement and is not promoted as an absolute conclusion.
