讓規則跟著專案走

AGENTS.md 是未來 AI agents 的 project manual。

它定義 canonical concepts、provenance、mastery、relationships、page structure 與修改邊界，讓新的 agent 即使沒有前次對話，也能沿用相同原則。

  • 一個 concept，只保留一個 canonical node
  • 來源、限制與不確定性必須可見
  • 沒有使用者確認，不進入 permanent knowledge
  • relationships 必須有證據與明確類型
  • 未來頁面沿用同一組內容與視覺結構
目標不是要求 AI 只做一次網站。目標是讓未來的 AI agents 能一致地延續這個系統。

Future agent task

“Add a new confirmed concept: Embedding”

AGENTS.md tells the agent to:

  1. check whether a canonical node already exists
  2. use confirmed knowledge only
  3. preserve provenance
  4. use typed relationships
  5. update the Concept Index and knowledge map
  6. preserve the shared visual structure
