# Week 9 AI Knowledge System Prototype

This directory is an isolated presentation prototype for the Week 9 assignment. It is derived from a larger AI Knowledge System and demonstrates concept-oriented knowledge organization across multiple course sources.

The prototype follows the principle that courses are knowledge sources, not the final knowledge structure. Shared ideas should converge on one canonical concept rather than being duplicated in separate course notebooks.

`AGENTS.md` records the project rules so future coding agents can continue without relying on previous chat context. This directory is not the full permanent knowledge base, and permanent concept content has not been copied into it.

No website or concept page has been implemented in this phase. See `docs/prototype-plan.md` for the approved prototype scope and next-phase plan.
