## Canonical-node principle

Each concept has one prototype content file regardless of the number of contributing courses. Course names remain source metadata inside the concept file; they are not used to create course-specific concept variants.

## Shared evidence policy

- Recorded mastery is displayed as 🟨 可以解釋, but no formal confirmation date or validation record exists.
- Existing first-person-labeled explanations may be presented only with the warning that authorship and confirmation metadata is unavailable.
- Course contributions are limited to what is recorded in the canonical concepts and course notes.
- Relationships are typed conservatively using the project rules; unresolved comparisons or derivations remain marked as unresolved.
- No external research or model-generated textbook expansion is included.
