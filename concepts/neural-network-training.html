Neural Network Training

Neural Network Training is the repeated process of adjusting learnable parameters so that a neural network’s output moves closer to its training target.

Why it matters

Training allows a model to change from its initialized behavior by using data, predictions, loss, gradients, and parameter updates. The notes also distinguish training from validation and testing: only training data updates parameters; validation observes training; test data is reserved for final evaluation.

Core idea

訓練是一個反覆的因果鏈，而不是單一 API 呼叫。

  1. data / batch
  2. forward computation
  3. prediction
  4. loss
  5. backpropagation computes gradients
  6. optimizer updates weights and biases
  7. repeat

All training samples being used once completes one epoch. A validation set can be evaluated after an epoch without backpropagation or parameter updates.
